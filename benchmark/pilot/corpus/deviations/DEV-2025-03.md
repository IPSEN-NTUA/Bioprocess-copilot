# DEV-2025-03: Power interruption

_SYNTHETIC BENCHMARK DATA - generated by a process simulator for a fictional lab (Larkspur Bio). Not real measurements._

**Author:** Mark Doherty  
**Date:** 2025-04-03

**Affected:** FB-010 (R4)

## Description
The lab UPS tripped on 02 Apr at about 12:20 (about 49.5 h into FB-010). R4 controller and feed pump were off for about 3.5 h; temperature and pH control resumed automatically, feed was restarted by hand.

## Root cause
UPS overload during building maintenance.

## Impact on data
No feed for ~3.5 h; online data missing for the same period. Run continued.

## Corrective action
Building services informed; R4 moved to a different UPS circuit.
