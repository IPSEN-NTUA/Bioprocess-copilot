# DEV-2025-02: Xylitol standard error

_SYNTHETIC BENCHMARK DATA - generated by a process simulator for a fictional lab (Larkspur Bio). Not real measurements._

**Author:** Tomas Reyes  
**Date:** 2025-04-04

**Affected:** HPLC sequence SEQ-20250321

## Description
The xylitol check standard in SEQ-20250321 read low against the new standard lot.

## Root cause
Xylitol stock standard prepared from a partially hydrated batch, so the xylitol calibration read low and sample results high.

## Impact on data
Xylitol values in SEQ-20250321 (P3 round 1 samples) are biased high: on re-analysis they were on average 6 % lower (range 0-12 %, n = 16). Other analytes unaffected.

## Corrective action
Retained samples re-analysed in SEQ-20250409 with fresh standards; corrected values in HPLC_results_2025-03.xlsx (comment column). Run owners to update their spreadsheets.
