# DEV-2025-04: Wrong C5 lot in feed

_SYNTHETIC BENCHMARK DATA - generated by a process simulator for a fictional lab (Larkspur Bio). Not real measurements._

**Author:** Mark Doherty  
**Date:** 2025-07-09

**Affected:** FB-024 (R3)

## Description
FB-024 was planned with lot C5-2503. The formate in the FB-024 feed sample was 7.7 g/L, close to the 7.9 g/L expected for C5-2502 at 60 % and well below the 14.2 g/L expected for C5-2503.

## Root cause
Feed for R3 prepared from the C5-2502 container (both containers in the same cold-room shelf).

## Impact on data
FB-024 is a C5-2502 run, not C5-2503. The lot comparison has only one C5-2503 run (FB-025, with enzyme).

## Corrective action
Containers relabelled and stored separately. Media sheet already shows the lot actually used.
