# Bench reactor set-up and data logging (R1-R4, GA-4)

_SYNTHETIC BENCHMARK DATA - generated by a process simulator for a fictional lab (Larkspur Bio). Not real measurements._

**Author:** Mark Doherty  
**Date:** 2025-01-10

| Vessel | Controller | Online export | Pumps logged as |
|---|---|---|---|
| R1, R2 | BioCtrl B1 | tab-separated text, one line every 10 min | pump counts (Acid_Pump, Base_Pump, Feed_Pump) |
| R3, R4 | VesselView VV-1 | csv, one line every 10 min | BASE_mL, ACID_mL in mL; feed only via FEED_BAL_g |

## Pump calibration (BioCtrl, checked 2025-01-10)
- Acid pump: 0.05 mL per count (1 M H2SO4)
- Base pump: 0.05 mL per count (2 M KOH)
- Feed pump: 0.10 mL per count

## Time stamps
- BioCtrl: the header gives 'Log start' and 'Inoculation'; Date/Time are wall-clock (dd.mm.yyyy).
- VesselView: Elapsed_h counts from the start of the recipe (when the logger is started), not from inoculation. The inoculation time is in the run sheets and the LIMS register (the S01 sample is taken ~6 min after inoculation).
- Feed: VesselView logs the feed bottle mass (FEED_BAL_g). BioCtrl does not log the balance; the feed bottle is weighed at the start and end of the run and written in the run workbook.

## Off-gas
GasLab GA-4 is connected to the R1 and R2 exhaust lines only (one stream file per run). Cycle every 30 min; dry gas, N2/O2/Ar/CO2 in %. Inlet air: 20.95 % O2, 0.04 % CO2, 0.7 L/min. RelTime[s] counts from the analyser start, which is not the inoculation time.
